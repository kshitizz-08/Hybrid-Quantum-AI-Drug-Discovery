# Hybrid Quantum-AI Drug Discovery Platform

> **Final-Year Engineering Project**  
> Computational drug candidate prioritization using AI prediction, QAOA quantum optimization, and AutoDock Vina molecular docking.

---

## 🔬 Project Overview

The **Hybrid Quantum-AI Drug Discovery Platform** is a full-stack, research-oriented web application designed to assist computational chemistry and drug discovery researchers in identifying, analyzing, optimizing, validating, and ranking potential drug candidates targeting specific biological targets (e.g., **EGFR — Epidermal Growth Factor Receptor / ChEMBL203**).

### 9-Stage Scientific Pipeline

```
DATA COLLECTION (ChEMBL raw IC50)
      ↓
DATA PREPROCESSING (Cleaning, unit standardization, pIC50)
      ↓
MOLECULAR FEATURE EXTRACTION (RDKit descriptors & Morgan fingerprints)
      ↓
AI-BASED PREDICTION (Random Forest & XGBoost bioactivity prediction)
      ↓
CANDIDATE FILTERING (Lipinski Rule of Five & Drug-likeness)
      ↓
QUANTUM OPTIMIZATION (QUBO formulation & QAOA via Qiskit + Classical baseline)
      ↓
MOLECULAR DOCKING (AutoDock Vina binding affinity calculations)
      ↓
VALIDATION (Methodology checks & confidence scoring)
      ↓
FINAL CANDIDATE RANKING (Weighted composite scoring & report generation)
```

| **DevOps & Infrastructure** | Docker, docker-compose |

## 🚀 Getting Started

### Prerequisites

- **Python**: 3.10+ (Tested on Python 3.13)
- **Node.js**: 18+ (Tested on Node 22 / npm 10)

---

### Backend Setup

1. **Navigate to backend directory**:
   ```bash
   cd backend
   ```

2. **Install Python dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Verify Environment Variables (`.env`)**:
   Ensure `.env` exists in the root directory:
   ```env
   DATABASE_URL=sqlite:///./hybrid_drug_discovery.db
   SECRET_KEY=change-this-to-a-strong-random-secret-key-before-production
   ALGORITHM=HS256
   ACCESS_TOKEN_EXPIRE_MINUTES=1440
   ```

4. **Start the FastAPI Backend Server**:
   ```bash
   python run.py
   ```
   *or using Uvicorn directly:*
   ```bash
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```

   - **API Documentation (Swagger UI)**: `http://localhost:8000/docs`
   - **Health Endpoint**: `http://localhost:8000/api/health`

---

### Frontend Setup

1. **Navigate to frontend directory**:
   ```bash
   cd frontend
   ```

2. **Install Node dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

   - **Frontend App**: `http://localhost:5173`

---

### Docker Setup (Optional / Future Use)

To run PostgreSQL, Redis, Backend, Celery, and Frontend with Docker Compose:

```bash
docker-compose up --build
```

## 📊 Database Schema (11 ORM Models)

1. `users` — Researcher user accounts & JWT auth
2. `targets` — Target biological proteins (EGFR / CHEMBL203)
3. `experiments` — Experiment tracking & pipeline execution states
4. `molecules` — Standardized molecular structures & SMILES
5. `model_versions` — ML model metrics (MAE, RMSE, R²) & artifact metadata
6. `predictions` — Predicted pIC50 bioactivity scores
7. `quantum_optimizations` — QAOA & QUBO problem definitions
8. `quantum_candidates` — Molecules selected by QAOA vs Classical solver
9. `docking_runs` — AutoDock Vina run settings & PDB receptor files
10. `docking_results` — Calculated binding energies (kcal/mol)
11. `final_rankings` — Weighted composite score matrix & ranking outputs
